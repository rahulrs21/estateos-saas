# Dashboard images

Banner photos in `banner/`, shown as a slideshow in the dashboard greeting. All are from Unsplash, used under
the [Unsplash License](https://unsplash.com/license) (free for commercial use, attribution not required), and
are also listed in the website builder's curated library (`src/modules/websites/stock.ts`). Each was downloaded
once at 1400×600 from images.unsplash.com and is bundled by Next.js, so the dashboard makes no third-party
request. Photos were chosen to show finished UAE homes and waterfront living, never construction sites.
